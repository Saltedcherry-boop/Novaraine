# NovaRaine Design Constitution

Version: 1.1

This document is the single source of truth for NovaRaine's visual language.

## Typography

- Poppins only

## Background

Midnight Navy

## Color Language

Soft Blush
Rose Pink
Nova Pink
Magenta
Deep Orchid
Electric Cyan
Emerald

Never use:

- Red
- Orange

## Inputs

- No value spinners
- No placeholder 0
- Empty fields
- Currency chips outside fields

## Dropdowns

One universal dropdown.

Every page uses the same component.

## Hover

- Lift
- Border brighten
- Soft pink edge light

No outdated hover cards.

## White Plate Mode

Every compartment supports White Plate Mode.

White Plate removes visual competition while preserving functionality.

## Component Rule

A new page may not invent a new component.

Every page must reuse the shared component library.
