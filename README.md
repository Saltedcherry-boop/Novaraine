# NovaRaine OS

> A trading operating system built around evidence, finance and purpose.

## Philosophy

NovaRaine is not a trading journal.

It is a connected operating system where one completed trade becomes one connected financial event.

Trade → Evidence → Finance → Purpose

Everything is connected through one source of truth.
